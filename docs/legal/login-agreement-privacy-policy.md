## 1. 重要提示

1. 本服务不面向中国大陆地区用户提供。若你位于中国大陆地区，或你的账号、设备、网络环境、付款方式、身份信息、实际使用行为显示你位于中国大陆地区，你不得注册、登录或使用本服务。

2. 你使用服务即表示你理解并同意，必要信息可能由平台及相关第三方服务商在提供服务所必需的范围内处理。

3. 本服务可能接入多个境内外第三方模型、云服务、支付服务、邮件服务、安全服务和日志服务。你选择使用特定模型或功能时，相关请求数据可能被传输给对应第三方服务商处理。

4. 请不要向平台提交国家秘密、工作秘密、商业秘密、未公开重大信息、未经授权的数据集、他人敏感个人信息或你无权提交给第三方模型服务商处理的信息。

## 2. 我们收集的信息

为提供服务、保障安全、完成计费和履行合规义务，我们可能收集以下信息：

1. 账号信息：邮箱、用户名、密码加密摘要、头像、语言设置、主题设置、登录状态、注册时间、账号状态、角色和权限。

2. 会员与计费信息：会员等级、会员有效期、余额、充值记录、订单记录、分组信息、倍率、赠送额度、扣费记录、退款记录、发票或支付相关必要信息。

3. API 与模型调用信息：API Key 标识、Key 名称、创建时间、所属分组、请求模型、渠道、平台、协议、输入输出 token 数、图片或音频计费信息、缓存读写信息、请求时间、响应时间、状态码、错误信息、费用、请求 ID。

4. 请求元数据：IP 地址、User-Agent、设备类型、浏览器信息、操作系统信息、登录时间、访问页面、来源页面、接口路径、网络状态、风控标记和安全审计日志。

5. 用户提交内容：你主动提交给模型的提示词、上下文、文本、图片、音频、视频、文件、链接、参数和模型返回内容。平台是否保存完整输入输出，取决于当前功能、日志设置、错误排查需要、合规要求和你选择的上游模型能力。

6. 通信信息：你通过邮件、客服、工单、反馈、申诉或其他方式与平台沟通时提供的信息。

7. Cookie 和本地存储：登录状态、偏好设置、语言、主题、条款同意记录、安全令牌和必要的会话信息。

## 3. 信息使用目的

我们可能将信息用于以下目的：

1. 创建和管理账号，完成登录、注册、密码重置、邮箱验证和身份校验。

2. 提供 API 中转、模型调用、会员权益、余额扣费、模型广场、工作台入口和其他产品功能。

3. 完成计费统计、订单处理、余额管理、分组倍率、使用记录展示和财务审计。

4. 防止账号盗用、恶意调用、绕过地区限制、刷量、撞库、攻击、欺诈、共享 Key、转售服务和其他滥用行为。

5. 排查错误、分析性能、优化服务、处理故障、改进模型路由和维护系统稳定性。

6. 履行法律、监管、审计、争议解决、用户申诉、权利保护和安全事件响应义务。

7. 向你发送必要的服务通知，例如登录提醒、计费异常、服务变更、条款更新、安全风险、账号处理结果和系统公告。

## 4. 第三方服务与数据传输

1. 当你选择某个模型、平台、工作台或第三方功能时，平台可能将完成请求所必需的数据发送给相应上游模型服务商、云服务商、支付服务商、邮件服务商、验证码服务商、安全服务商或日志服务商。

2. 第三方服务商可能位于不同国家或地区，也可能根据其自身条款和隐私政策处理数据。

3. 你应确保自己有权将相关内容提交给平台及第三方服务商处理。如果你不希望特定内容被第三方模型服务商处理，请不要通过本服务提交该内容。

4. 平台将尽量按照最小必要原则传输数据，但模型调用本身通常需要将你的输入、参数和上下文传输给上游服务商，才能生成响应。

5. 平台不会出售你的个人信息。未经你同意，平台不会将你的个人信息用于与服务无关的广告投放或画像营销，法律允许或另有说明的除外。

## 5. 数据存储与保留

1. 账号、订单、计费、余额、会员、API Key、风控和审计记录，将在账号存续期间以及为履行合同、争议处理、财务审计、安全合规所需的期限内保存。

2. API 调用日志和错误日志的保存期限，取决于平台后台配置、排障需要、安全审计和合规要求。平台可对日志进行脱敏、聚合或删除。

3. 你注销账号或服务终止后，平台将按照适用法律、业务结算、争议处理、安全审计和合规要求删除、匿名化或继续保留必要信息。

4. 因备份、缓存、日志归档、财务记录或安全审计需要，某些信息可能不会立即从所有系统中删除，但平台将限制其访问和使用范围。

## 6. 数据安全

1. 平台采用合理的技术和管理措施保护信息安全，包括但不限于访问控制、密码加密存储、权限隔离、日志审计、安全监控、备份、密钥管理和最小权限原则。

2. 互联网传输和存储无法保证绝对安全。你应妥善保管账号、密码、API Key、访问令牌和设备，不要在不可信环境中登录或泄露凭证。

3. 如发生可能影响你权益的数据安全事件，平台将根据适用法律和事件影响，通过邮件、站内通知、公告或其他合理方式告知你，并采取补救措施。

## 7. 你的权利

在适用法律允许和技术可行范围内，你可以：

1. 查看、修改账号资料和部分偏好设置。
2. 重置密码、删除或重建 API Key。
3. 查询会员、余额、订单和使用记录。
4. 要求更正不准确的信息。
5. 要求删除账号或停止使用服务。
6. 要求说明个人信息处理规则。
7. 对账号限制、封禁或异常计费提出申诉。

为保护账号安全，平台可能要求你完成身份验证后再处理上述请求。
